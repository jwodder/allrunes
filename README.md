This is the source repository for the [allrunes](https://ctan.org/pkg/allrunes)
CTAN package, providing the ability to typeset a wide variety of [runic][]
symbols in LaTeX.  See [`src/README.txt`](src/README.txt) for installation
instructions, and see [`src/allrunes.pdf`](src/allrunes.pdf) for usage
instructions.

[runic]: https://en.wikipedia.org/wiki/Runes

I took over this project from its original maintainer in 2026, mostly so that I
could fix a breaking incompatibility with newer LaTeXes.  I do not foresee any
future nontrivial developments for this package.
